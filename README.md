# 📸 CaptureX

> **A sleek, modern photography sidebar UI built with pure HTML & CSS.**

CaptureX is a simple and elegant front-end project designed to showcase a fullscreen photography layout with an animated sidebar navigation menu.

---

## ✨ Features

- 📷 Fullscreen background image
- ☰ Hamburger menu
- ❌ Smooth sidebar open/close animation
- 🎨 Glassmorphism-inspired sidebar
- 🖼️ Gallery section
- ⚡ Shortcuts
- 🎞️ Exhibits
- 📅 Events
- 🛍️ Store
- 📞 Contact
- 💬 Feedback
- 🌐 Social media icons
- ✨ Interactive hover effects
- 📱 Responsive viewport setup
- 🚫 No JavaScript required

---

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling, layout & animations
- **Poppins** — Google Font
- **Font Awesome** — Icons

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Make sure `photo.jpg` is in the same folder as `index.html`.
4. Open `index.html` in your web browser.
5. Click the **☰ menu icon** to open the sidebar.

No installation or JavaScript setup is required.
